# TraceForge 0.13.1 — Windows PCM

Install `TraceForge-0.13.1-KiCad10-PCM.zip` from KiCad 10's Plugin and Content
Manager using **Install from file**. Close all KiCad windows before updating.

## Changes

- Via-in-Pad Inspector groups affected vias under each component. Selecting a
  result highlights and zooms to the via.
- Via Stitching has a cleanup view for standalone through vias. It can select
  listed vias for manual deletion and shows their connected copper-layer count.
- Signal selection and other KiCad operations show a loading animation.
- Inspector focus skips redundant whole-board renderer refreshes. Removing
  stitching vias, generated fanout or selected vias leaves zone refill to the
  user; press **B** in KiCad before DRC or manufacturing export.

Placement actions that need filled-zone connectivity still refill zones for
validation. The macOS build is published separately as a preview.
