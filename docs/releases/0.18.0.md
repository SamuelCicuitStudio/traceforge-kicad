# TraceForge 0.18.0 — local testing build

This build is installed locally for testing in `Documents/KiCad/10.0/scripting/plugins/traceforge` (manual plugin folder). It does not publish a GitHub release or change the public PCM release pointer.

## Components → Search / details

- Native LCSC-only catalog inside TraceForge; no embedded browser, Electron service or PySide6 runtime is needed for research.
- Category tree, keyword / exact MPN / exact C-number search, live category-specific filters arranged horizontally above results. Filter selection uses OR within a group and AND across groups.
- Stock-only filtering, price sorting, 25 / 50 / 100 results per page and next/previous pages. LCSC's 5,000-result search limit is disclosed; narrow filters to search larger categories.
- Product thumbnails, visible retail stock and four price breaks per row. TraceForge dark colors, gold prices, green available stock and blue action buttons.
- Selecting a result opens compact specifications, all price breaks and independent symbol / footprint / STEP states. Hide details restores result-list space. The filter strip scales with panel height.
- **Use in project** copies exact identity, package, relevant ratings and passive category to Assets / import. Passives retain a reusable generic symbol. A missing footprint can be staged separately. Assets remain staged until the existing preview/import transaction is applied.
- CAD metadata lookup and STEP header verification run independently. They do not claim that package geometry or orientation was verified. Existing converter helpers remain necessary for CAD conversion/import.

## Manufacturing → BOM Cost

- Reads the full saved root schematic or the live PCB. Saved-schematic costing can run without a live native PCB helper.
- Reads supplier-field spelling variants and LCSC product links; otherwise searches once per distinct MPN. Only a unique exact MPN result from a complete result page can supply an inferred LCSC code. Ambiguous, truncated and unavailable results remain unpriced.
- Checks the supplier quote MPN again, groups repeated identified parts, applies board count, spares, minimum order / order multiple and quantity price tiers using decimal arithmetic.
- Shows dated observations, known-price subtotal, unpriced lines and stock shortages. Exports CSV plus JSON containing identity-resolution evidence. It never changes component fields or substitutes parts in the project.
- Retail USD parts only. PCB fabrication, assembly, shipping, taxes and JLCPCB assembly inventory are outside this estimate.

## Schematic access and one component contract

KiCad 10 has no schematic plugin toolbar API. A supported launcher is registered under **Tools ? Generate Legacy Bill of Materials ? TraceForge Components (LCSC) ? Generate**. It opens only Components with the current schematic project, without a running PCB Editor. The launcher returns immediately to KiCad. The Components window also has a project picker.

Import installs project-local libraries; **Copy symbol ID for Place Symbol (A)** gives the qualified ID to paste into KiCad's symbol chooser. It does not place or rewrite live schematic instances. For a newly registered library, refresh/reopen the chooser if necessary.

`pcb/assets/component-schema.json` is the canonical field contract. Run `tools/sync_component_schema.py --check` against the skill checkout to verify the plugin and schematic-authoring copies. The package includes its offline copy. Canonical names include Manufacturer, MPN, LCSC Part #, Footprint, Datasheet, Description, Package and separate electrical ratings.

New exact passive symbols copy small generic graphics and retain per-part defaults, including the qualified footprint. Shared templates are unchanged. Resistor tolerance, and capacitor voltage/tolerance/dielectric, are visible when provided. Rated current, saturation current, DCR and ferrite test frequency remain distinct. New PCB footprints show Reference on F.SilkS and hide other fields. Sourced unknowns remain missing; downloads do not certify geometry or orientation.

Verification states use green for confirmed metadata/header, amber for linked/unverified STEP and red for unavailable/failed checks. Green metadata does not certify geometry. BOM Cost has a large green subtotal at the upper right with an amber incomplete-BOM count when needed.

For another installation, run the packaged `register_schematic_components.py --plugin <installed-folder> --python <KiCad-pythonw.exe>` with Schematic Editor closed. The registrar backs up its preferences, appends only the launcher entry and preserves all other settings, including UI sizes. No KiCad preferences are reset.

## BOM row research, assignment and PCB focus

Right-click a BOM Cost row (or double-click it to research):

- **Research MPN / set LCSC information** switches to the existing Components tab, prefilled with that row's MPN.
- **Choose replacement information (keep footprint)** uses that same Components tab to search for another exact part.
- **Highlight and zoom in PCB** uses the same transient highlight and explicit zoom commands as Signals, targeting the row's footprint references. A BOM from another project cannot focus the active board.

Select a result, inspect its information and click **Set information for selected references**. The tool reloads supplier details, merges known exact-project metadata, rejects known passive value/package mismatches and writes canonical purchasing/rating fields to the selected schematic instances and live PCB footprints. Value, reference, lib_id, footprint assignment, UUIDs, pads, nets, placement and routing are retained. Shared generic symbol/footprint libraries are never rewritten by this action. Missing replacement ratings are cleared rather than inherited from another MPN. The BOM recalculates afterwards; save the PCB to retain its undoable field changes.

The source references are captured from the BOM calculation. If the schematic identity/value/footprint or live PCB changes before assignment, the operation stops. Saved schematic writes use file hashes, backups and a rollback journal; a failed native update restores this transaction's saved changes without overwriting later user edits. Project reference assignments are recorded in `libraries/traceforge-reference-info.json`.

**Save and close Schematic Editor before Set**: KiCad 10 has no supported live schematic field-edit API. The PCB can remain open. If a repeated child-sheet symbol serves additional unselected references, assignment is blocked until all affected instances are included or their sheet is split. Native PCB Undo restores PCB fields only; schematic backups are kept with the transaction under `review/component-imports/`.

LCSC name search now falls back to its public website global-search endpoint when the product-list endpoint omits a name. Live verification: `GRM1555C1H330JA01D` resolves to `C76964`, stock 0; stock-only search excludes that part. There is no hardcoded MPN/code mapping. Supplier identity is checked again before assignment.

Restart PCB Editor after installing this local update to load the new native focus/metadata actions. No public release is published by this work.

## Integrated BOM navigation and parent categories

BOM research does not open another window or create another research panel. It reuses the main Components ? Search / details tab. A reference banner and scoped Set button retain the BOM assignment context while browsing; **Return to BOM** cancels that context and returns to the report. Successful assignment returns to BOM Cost and recalculates it. Normal component import remains available after leaving assignment mode.

Clicking a category starts category browsing immediately, clearing the previous keyword/MPN and component-specific parameter selections. Explicit stock-only and sort preferences remain. Parent categories such as Capacitors and Resistors include all their leaf subcategories; the provider's leaf-only queries are combined with paging, price ordering and merged filter options. Individual supplier result limits remain disclosed. A single-child parent is resolved to its child automatically. Live checks returned products and filters for both the main Capacitors and Resistors parents.

Close and reopen the TraceForge panel to load this frontend update; these navigation changes do not require restarting PCB Editor.

## Component highlight/zoom correction

BOM focus now calls the existing Signal `highlight` operation with reference IDs, followed by its explicit `zoom` operation. It does not gate a transient render highlight on `GetCurrentSelection()`, which can be empty despite footprint flags being set. Highlights participate in the normal previous-highlight cleanup, preserving earlier user selections. The status distinguishes successful zoom from an unavailable native zoom control. The frontend uses established helper commands, so closing/reopening TraceForge is sufficient for this correction.

## BOM focus runner and cancellation correction

The BOM page now implements the `message` and `invalidate` callbacks required by the shared board-operation runner. Previously that runner could fail before dispatching the highlight/zoom RPC, leaving its pending counter set. The regression test now uses the actual runner, including successful focus, a failing helper response and subsequent busy-state recovery. Component focus issues the same `highlight(nets=[], refs=..., zoom=True)` call as Signals, followed by explicit zoom.

The main Cancel button routes to ongoing research, CAD staging, reference assignment, BOM pricing, manufacturing checks and cancellable native previews. It remains usable for these independently scheduled tasks. Research cancels queued futures and suppresses old response generations. Pricing/identity workers stop waiting for blocked provider calls, retain a separate cancellation event for each run, discard late progress/results and never publish a cancelled total. Provider I/O checks its cancellation event and has a bounded connection timeout; an underlying request can take time to close after the UI has cancelled it.

Read-only manufacturing CLI checks terminate their owned child process. Project setup, output publication, library imports and reference-field writes stop before their commit boundary; an atomic transaction already committing finishes rather than leaving partial files or board changes. The UI reports that distinction. Signal refresh cancellation retains prior values and discards the new result at the next safe return. Other noninterruptible native board edits complete safely instead of pretending they were rolled back.
