# TraceForge 0.13.3 — Windows PCM

This is a stable GitHub release for **KiCad 10 on Windows**. Install
`TraceForge-0.13.3-KiCad10-PCM.zip` from KiCad Manager's **Plugin and Content
Manager > Install from file**, then close and restart KiCad. The release contains
the Windows PCM ZIP and its SHA-256 checksum only. The older macOS preview is
separate and has no 0.13.3 update.

## Changes

- Routed signals without a valid netclass timing profile now say **timing profile
  missing**. They are not shown as 0 ps / matched and get no generated timing
  DRC target. The profile must cover each routed copper layer.
- Automatic chain discovery no longer creates a 15 ps source-net limit. Source
  PCB ps/mm still sums the first net's routed copper for review; an explicit
  project limit remains available in the Signal Chain Editor.
- Via-in-Pad Inspector detects full pad overlap, partial hole overlap and
  annulus-only overlap on all nets. It groups and colors the results, shows both
  net names, and focuses a clicked via in PCB Editor.
- Via Stitching opens standalone-via cleanup as a full-height view in the same
  tab and has an option to avoid SMT pads.
  Cleanup selects candidates for manual deletion; it does not delete them.
- Trace Cleanup finds narrow straight tracks fully covered by wider same-net
  copper, including offset or angled cases, and keeps the wider track intact.
- Empty KiCad Selection Filters now produce specific guidance during picking
  and selected-item actions. Board-wide scans still work without PCB selection.
- Delete actions defer zone refill. Press **B** in PCB Editor when ready.

The [README](../../README.md) gives installation steps, a feature map and a
troubleshooting table for timing profiles, source-net readings, selection
filters, via classifications, cleanup and zone refill.
