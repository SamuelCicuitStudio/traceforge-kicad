# TraceForge 0.12.7 for KiCad 10 on Windows

This testing release makes differential tuning explicit and includes the tooling added since 0.12.1.

## Signal matching
- Differential members are labeled `[DIFF]` with their partner; single-ended signals are labeled `[SE]`. RAM DQS and clock pairs remain visibly differential inside mixed byte/command groups.
- Selecting a signal explains KiCad pair-length, pair-skew or single-track tuning and displays the configured limits.
- Intra-pair P/N skew and inter-pair delay spread are independent checks. Valid pairs no longer inherit one tight window around the longest unrelated signal.
- Whole-chain tuning accounts for series-net offsets, vias and configured package delay. Source PCB segment limits exclude package delay.
- Pending differential partners cannot be reported as matched. Additional pad contacts are distinguished from source-segment limit violations.

## Other tools included
- Manufacturing workflow for saved KiCad projects, with PCBWay and PCBPower package exporters and review checks.
- Native feature-tab shortcuts and component rotation tools, alongside trace cleanup, teardrops, rounded corners, BGA fanout and via tools.

## Installation
Download `TraceForge-0.12.7-KiCad10-PCM.zip`. In KiCad Manager, open **Plugin and Content Manager > Install from file**, select the ZIP, then close all KiCad windows and reopen PCB Editor. The Windows ZIP is an alternative standalone installation; use one installation method.

## Validation and limits
Local validation: 163 tests passed, one environment-specific skip; real wxPython signal-row checks; differential-matching regressions against the extracted PCM archive; release lint and package integrity checks.

Windows and KiCad 10 only. This is a **testing** package. Manufacturing export needs kicad-cli and a separate Python with openpyxl. Hardware timing budgets and manufacturing approval remain project decisions.

Native tuning-rule windows are snapshots: regenerate after routing changes. KiCad only sees the net segment being tuned; a series-part path may require nonzero local skew to achieve whole-chain matching. Package-delay accuracy depends on supplied values. Follow the project constraints and run DRC before signoff.

`SHA256SUMS.txt` covers both downloadable archives. The official KiCad catalog update is submitted separately for maintainer review.
