# TraceForge 0.13.1 — macOS preview

Download `TraceForge-0.13.1-KiCad10-macOS.zip`, extract it to a permanent folder,
close KiCad 10, and run from the extracted folder:

```sh
bash tools/install_native_bridge_macos.sh --python /absolute/path/to/python3
```

The chosen Python must import `wx`. The installer defaults to KiCad 10's
`~/Documents/KiCad/10.0/scripting/plugins` folder. If your installation uses a
different plugin folder, pass `--plugins-dir /absolute/path`. Restart PCB Editor.

This preview includes the 0.13.1 via inspection, stitching cleanup, loading
animation and reduced zone redraw behavior. Archive integrity, Python compilation
and installer mechanics are checked in CI. **Live board editing, toolbar, Undo and
manufacturing workflows still need testing in KiCad 10 on macOS.** Try it on a
noncritical board and report your macOS version, KiCad version, chip architecture
and any error messages. KiCad 11 support is not claimed.
